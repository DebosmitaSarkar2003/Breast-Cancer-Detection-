# Breast Cancer Detection Model 🎗️

A Machine Learning project that classifies breast tumors as Malignant or Benign based on the Wisconsin Diagnostic Data Set using Logistic Regression.

🎓 **Academic Context:** *This project was developed as part of the Artificial Intelligence coursework during the 6th semester of my B.Tech in Computer Science and Engineering.*

## 📌 Overview
This project uses the famous **Kaggle Breast Cancer Wisconsin (Diagnostic) Dataset** to predict if a tumor is:
* **Malignant (M)** - Cancerous
* **Benign (B)** - Non-cancerous

The model leverages a Logistic Regression algorithm and achieves an accuracy of approximately **96-98%** on the test data.

## 📂 Dataset
You can download the dataset from Kaggle here:
[Breast Cancer Wisconsin (Diagnostic) Data Set](https://www.kaggle.com/uciml/breast-cancer-wisconsin-data)

*Note: Rename the downloaded file to `data.csv` and place it in the root project folder before running the code.*
